# kanji-test

ブラウザだけで動作する、シンプルな漢字小テスト作成ツールです。

**おすすめの使い方**
①本体を生成AIに食わせる
②問いたい漢字(もしくは熟語)を15こ用意し、その言葉を使った短めの文章を出力させる
③②で出力したものを、①のファイルで実際に使用できるJASONファイルで送るように指示する

問題文を入力し、出題したい箇所を指定することで、縦書き・A4横向きの漢字小テストを作成できます。読み問題・書き問題の両方に対応しており、問題数に応じた点数欄、氏名欄、実施日、学年、解答用紙なども自動で生成できます。

**主な機能**
複数行の文章をまとめて入力
1行につき1問として自動生成
出題箇所を指定して問題化
読み問題／書き問題の切り替え
全問を一括で読み／書きに変更
書き問題では、ひらがなで入力した読みをカタカナに変換
正答の自動入力
問題の並び替え
A4横向き・縦書きレイアウト
実施日、氏名、学年、点数欄
問題用紙／解答用紙の切り替え
印刷機能
JSON形式での問題データ保存・読み込み
印刷前の未入力チェック
プレビューの自動サイズ調整
使い方
HTMLファイルをブラウザで開きます。
問題文を入力します。
改行ごとに1問として認識されます。
各問題で、出題したい文字列を指定します。
「読み」または「書き」を選択します。
必要に応じて正答や読みを入力します。
右側のプレビューで完成形を確認します。
問題または解答を印刷します。
必要であればJSONファイルとして保存し、後から読み込むこともできます。
データの取り扱いについて

このツールは、基本的にHTMLファイル単体で動作します。

入力した問題文、氏名、日付、正答、保存データなどが、外部のサーバーへ送信されることはありません。問題作成やJSON保存・読み込みなどの処理は、すべて使用しているブラウザ内で行われます。

そのため、インターネット接続がない環境でも使用できます。

※外部フォントなどを追加した改造版を使用した場合は、その部分について通信が発生する可能性があります。
